## 🔍 Quick Reference

### Environment Variables

```bash
# AI Providers
LLM_PROVIDER=openai|anthropic|google|ollama
LLM_MODEL=<model-name>
LLM_TEMPERATURE=0.7
LLM_MAX_TOKENS=2048

# Provider-specific
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
GOOGLE_API_KEY=AIza...
OLLAMA_HOST=http://localhost:11434

# Proxy
JARVIS_HTTP_PORT=8080
JARVIS_UI_PORT=9090
```

See [LLM_INTEGRATION.md - Configuration](LLM_INTEGRATION.md#configuration) for complete list.

### Commands Quick Reference

```bash
# Test Data Generation
jarvis gen generate-testdata --spec api.yaml
jarvis gen generate-from-schema --schema user.schema.json

# Failure Analysis
jarvis analyze analyze-failures
jarvis analyze analyze-endpoint /api/users

# Test Scenarios
jarvis gen generate-scenarios --path specs/
jarvis gen generate-test --path specs/ --output tests/

# Traffic Inspector
jarvis proxy --record
jarvis proxy --api-validate --api-spec api.yaml

# Utilities
jarvis setup
jarvis version
jarvis certificate --cert-dir ./certs
```

See [README.md - Command Structure](../README.md#command-structure) for complete list.
